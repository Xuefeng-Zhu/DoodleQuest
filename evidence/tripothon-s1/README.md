# DoodleQuest — Tripothon S1 media kit

Prepared October 3, 2026 for **Game + Tripo**. A remote draft has been created; no final event entry has been submitted. Its Team step requires a full name, email and role, and later steps remain locked pending those details. Private draft identifiers and contact details are excluded from this public kit.

## Public demo and source

- [DoodleQuest](https://doodlequest-six.vercel.app) runs on Vercel Hobby with Neon Free. Play the [Pip example](https://doodlequest-six.vercel.app/example), or [create a gift](https://doodlequest-six.vercel.app/create) with the bundled drawing. Hosted persistence, sharing and revocation were verified.
- The public demo uses authored procedural Pip and has paid Tripo generation disabled. It does not reproduce the recorded Tripo-generated Mom & Dad hero. Hosted Tripo generation, Workflow execution and live rigging remain unverified.
- The [repository](https://github.com/Xuefeng-Zhu/DoodleQuest) is public, and the deployment source has been merged into `main`. Source and reviewed media are accessible without a GitHub account.
- Direct reviewed media: [walkthrough MP4](https://raw.githubusercontent.com/Xuefeng-Zhu/DoodleQuest/main/evidence/tripothon-s1/walkthrough.mp4) and [asset board PNG](https://raw.githubusercontent.com/Xuefeng-Zhu/DoodleQuest/main/evidence/tripothon-s1/asset-board.png). These public links are ready for the portal's media fields once accessible; no portal upload is claimed.

## Files to review

- `entry-copy.txt`: paste-ready project copy; adapt it to the portal's actual fields.
- `walkthrough.mp4`: 87.33-second silent walkthrough using the real Tripo-generated Mom & Dad hero. Local gift links are masked. Captures were sampled at approximately 5 fps, assembled at 24 fps, with tool-idle gaps removed and generation waits visibly accelerated 8×. It is not a continuous real-time capture.
- `asset-board.png`: one-page visual board for upload.
- `asset-board.html`: responsive board; keep its sibling image files together when sharing it.
- `source-drawing.png`: OpenAI image-generated generic adult-couple illustration used as Tripo input. The child-to-parents story is fictional.
- `hero-preview.jpg`, `personalization.jpg`, `recipient-opening.jpg`, `letter.jpg`, `signature.jpg`: actual local product captures.
- `verification.json`: sanitized provenance and file verification. Raw task IDs, tokens, credentials and runtime data are excluded.

The recording predates the latest background and motion work. It establishes saved-model reuse in a local gift, not hosted availability of that generated hero or successful live Tripo rigging. The bundled procedural Pip example is separate from this generated hero. `verification.json` records the historical local audit; its deployment-unverified entry predates the subsequent hosted example checks documented in [COMPLETION.md](../../docs/COMPLETION.md).
