Model metadata records provider task, model version, byte/triangle counts and validation. The owner-only provenance view traces input revision → actual provider/application states → stored model → approved playable character.

An uncropped, metadata-stripped original remains protected separately from the generation reference. Recipients see it only with explicit creator permission. No sketch enhancement is implemented.

`evidence/` contains actual locally rendered product captures, not promotional concept art. Its walkthrough uses the explicitly procedural sample and does not establish Tripo output quality.
